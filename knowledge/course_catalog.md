## CS101 Introduction to Programming (3 credits)

Prerequisites: none. Instructor: Dr. Inna Pivkina.
A first course in programming for students with no experience. Variables, conditionals, loops, functions, lists and debugging, taught in Python through small weekly projects. Core course.

## CS102 Data Structures (3 credits)

Prerequisites: CS101. Instructor: Dr. Enrico Pontelli.
How to organize data so programs run efficiently: arrays, linked lists, stacks, queues, hash tables, trees and graphs, with an introduction to analyzing running time. Core course.

## CS150 Web Programming (3 credits)

Prerequisites: CS101. Instructor: Dr. Jonathan Cook.
Building websites and web applications: HTML, CSS, JavaScript, client and server communication, forms, and connecting a site to a database. Students build and deploy their own web app. Elective.

## CS201 Algorithms (3 credits)

Prerequisites: CS102, MATH150. Instructor: Dr. Son Tran.
Designing and analyzing algorithms: sorting, searching, divide and conquer, greedy methods, dynamic programming and graph algorithms, with proofs of correctness and efficiency. Core course.

## CS210 Computer Systems (3 credits)

Prerequisites: CS102. Instructor: Dr. Roopa Vishwanathan.
How computers run programs underneath: binary data, machine-level code, memory and caches, processes, and the C language. Prepares students for operating systems and networking. Elective.

## CS220 Databases (3 credits)

Prerequisites: CS102. Instructor: Dr. Huiping Cao.
Storing and querying large amounts of data: the relational model, SQL, database design and normalization, indexing and transactions. Core course.

## CS240 Computer Security (3 credits)

Prerequisites: CS102. Instructor: Dr. Roopa Vishwanathan.
Protecting computer systems and data from attackers: cryptography, authentication, common software vulnerabilities, network attacks and defenses, privacy, and ethical hacking in a lab setting. Elective.

## CS250 Software Engineering (3 credits)

Prerequisites: CS102. Instructor: Dr. Jonathan Cook.
Building large programs in teams: requirements, design, version control with Git, testing, code review and project management, through a semester-long team project. Elective.

## CS260 Data Mining (3 credits)

Prerequisites: CS102, MATH260. Instructor: Dr. Huiping Cao.
Finding patterns in large datasets: data cleaning, clustering, classification, association rules and anomaly detection, applied to real data. Elective.

## CS301 Operating Systems (3 credits)

Prerequisites: CS210. Instructor: Dr. Satyajayant Misra.
How an operating system manages a computer: processes and threads, scheduling, synchronization, memory management, file systems and virtualization. Elective.

## CS310 Artificial Intelligence (3 credits)

Prerequisites: CS201. Instructor: Dr. Christian Wayllace.
Building intelligent agents: search, planning, knowledge representation, reasoning under uncertainty, reinforcement learning and an introduction to large language models and AI agents. Elective.

## CS320 Machine Learning (3 credits)

Prerequisites: CS310, MATH250. Instructor: Dr. Mingzhou Song.
Teaching computers to learn from data: regression, classification, neural networks, model evaluation and statistical learning theory. Elective.

## CS330 Computer Networks (3 credits)

Prerequisites: CS210. Instructor: Dr. Satyajayant Misra.
How the Internet works: network layers, TCP/IP, routing, wireless and mobile networks, and network performance and security. Elective.

## CS340 Bioinformatics (3 credits)

Prerequisites: CS201. Instructor: Dr. Mingzhou Song.
Computing for biology and medicine: DNA and protein sequence analysis, gene expression data, biological networks and statistical methods for genomics. Elective.

## CS400 Senior Capstone (3 credits)

Prerequisites: CS201, CS220. Instructor: Dr. Jonathan Cook.
A semester-long team project building a complete software system for a real client, from requirements to delivery, with presentations and documentation. Core course, usually taken in the final year.

## MATH150 Discrete Mathematics (3 credits)

Prerequisites: none. Instructor: Dr. Elena Ruiz.
The mathematics of computer science: logic, proofs, sets, functions, counting, relations and graph theory. Core course.

## MATH160 Calculus I (4 credits)

Prerequisites: none. Instructor: Dr. Marcus Webb.
Limits, derivatives, and integrals of functions of one variable, with applications to rates of change and optimization. Core course.

## MATH250 Linear Algebra (3 credits)

Prerequisites: MATH160. Instructor: Dr. Elena Ruiz.
Vectors, matrices, systems of linear equations, determinants, eigenvalues and eigenvectors, with applications in graphics and machine learning. Elective.

## MATH260 Probability and Statistics (3 credits)

Prerequisites: MATH160. Instructor: Dr. Marcus Webb.
Probability, random variables, distributions, estimation, hypothesis testing and regression, for analyzing data and experiments. Elective.

## ENG101 Academic Writing (3 credits)

Prerequisites: none. Instructor: Dr. Nora Castillo.
Writing clear, well-organized essays and arguments, using sources and citations correctly. Core course.

## ENG201 Technical Writing (3 credits)

Prerequisites: ENG101. Instructor: Dr. Nora Castillo.
Writing for technical audiences: documentation, reports, proposals, user manuals and presentations. Elective.

## PHYS101 Physics I (4 credits)

Prerequisites: MATH160. Instructor: Dr. Owen Harper.
Mechanics: motion, forces, energy, momentum and rotation, with laboratory work. Elective.
